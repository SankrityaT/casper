# Casper: names inside the manor (Oct 30)

The product is a haunted manor. Teams get wings, projects are rooms, and agents live in them.
We reference the film's house through the theme only; we don't use "Whipstaff" (it belongs to the film).
Every themed name sits next to a plain one the first time it appears, so nothing is a riddle.

| Plain | In Casper | Where it shows |
|---|---|---|
| Org / workspace | **Manor** ("Acme Manor") | sidebar header, search ("Search the manor"), breadcrumbs |
| Space / team | **Wing** ("Engineering wing") | space switcher, settings, onboarding step 1, "Engineering wing only" |
| Room / project | **Room** (unchanged) | everywhere |
| Needs you / approvals inbox | **The bell** | rail tooltip, sidebar item with count, "Ringing Sankritya's bell" |
| Memory + decision log | **Library** | settings nav, rail tooltip |
| Activity log | **Guestbook** | settings nav |
| Guests from other companies | **Guests** (unchanged) | sharing |
| Join command | **Knock**: `npx casper knock` | hero, onboarding, settings |

Not themed on purpose: Agents, Computers, Rules and approvals, Usage and spend, Members. Those are
things people need to find fast, and the brief says readable first.

## The house crew (the manor's own ghosts)

| Ghost | Job |
|---|---|
| **Casper** | Host: greets people, turns calls into tasks, sums up rooms |
| **Stretch** | Dispatcher: routes untargeted work, enforces claim-once, stops agent ping-pong (hop limit) |
| **Fatso** | The Library: eats transcripts, docs and decisions; answers from the wing only |
| **Stinkie** | Watchdog: stuck agents, loops, risky actions; rings the bell |

Also: **Lazarus** = the room coming back after a crash (the Terse moment). **Midnight pass** = guest access that expires at midnight.
