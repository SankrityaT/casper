# YC Fall 2026 batch: who overlaps with Casper (Oct 30)

Pulled all 195 F26 companies from YC's public directory (ycombinator.com/companies?batch=Fall 2026) and read the ones about agents, teams, oversight or computers.

## Closest
- **Tilo** (tilo.so, 2 people): an operating system "built for AI agents to work alongside people". Apps expose actions so agents skip screenshots. "Any number of people and agents can work in one workspace in real time, across apps", you see what each agent does, and changes can be undone. Shared from the browser. **Closest to our live shared computers.** No cross-owner, canvas or approvals mentioned.
- **Spacesheep** (spacesheep.dev, 2): where agents' output lands as a "space" the team takes in at a glance. Comment, @mention, ask its agent, live on every screen, versioned, searchable. **Closest to "team works on agent output together."** It's about the output, not watching agents work.
- **Stacktrace** (stacktrace.ai, 3): "See and control what your agents actually do". Sees every action, enforces bounds, steps in when an agent drifts. **Overlaps our approvals and oversight**, but as a control layer, not a workspace.
- **GodHands** (godhands.ai, 2): captures "the steps, decisions and exceptions that never get written down" and turns them into playbooks and agents. **Overlaps edge 3 (decisions).**

## Infrastructure (possible partners, not rivals)
- **Agent Relay** (host): "your agent can answer a colleague's agent while you sleep". We build on it.
- **Terse** (host): mentions "multiplayer agent frameworks". We build on it.
- **Boat**, **Superserve**, **Maritime**, **Agent 37**: computers for agents. Boat and Superserve are both F26.
- **Boxes.dev**: Claude Code and Codex on parallel cloud computers, started from Slack and Linear, with agent swarm coordination. Coding only.
- **Acyclic Labs**: agent swarms on workspace forks.

## Takeaway
No F26 company combines the team room, live agent computers you can take over, asking any agent why, and decisions from approvals. Each piece exists in one of them:
- Tilo: live shared computers
- Spacesheep: the team surface
- Stacktrace: oversight
- GodHands: decisions

The combination, and the room where they meet, is ours. Expect Tilo and Spacesheep to drift toward us.

# TalentOS (talentos.so), not in F26: the closest competitor of all

From its site and llms-full.txt, Oct 30:
- **Pitch:** "a multiplayer AI workspace where people and the agents they already use, like Claude Code and Codex, work together in shared Rooms."
- **Already shipped:**
  - Rooms with a thread, files and a brief
  - each person's own AI "Talent", with any model
  - Claude Code or Codex joins with one prompt ("Maya's Claude Code"); file changes come in as suggestions
  - approvals (money, irreversible actions and calendar writes always ask) and a receipt for every job
  - meeting notes with action items (Oct 5)
  - a live browser pane to watch the AI browse (Sept 22)
  - shared scratchpads, and Slack and iMessage
- **Also:** a blog post on "agents working together without duplicate work". It's process advice (shared brief, clear owners), not a mechanism. Max plan is $199 per member per month.
- **Founder:** James Win (@Win22James), who replies to posts promoting it. He also names a competitor, Kylon.
- **What we haven't seen from them:**
  - an infinite canvas or spatial view
  - one computer per agent that the team can take over (theirs is a browser pane you watch)
  - claims that stop two agents doing the same work
  - asking someone else's agent why
  - state that survives a crash
  - characters or a brand with personality. The UI is a standard chat plus file cards.
